# AI Solution Design: Insurance Fraud Detection

## Overview
This repository contains the problem formulation, data requirements, and model selection for an AI-powered Claims Triage and Fraud Detection system in the Insurance domain. The goal of this solution is to reduce manual processing hours and improve customer satisfaction while effectively catching fraudulent claims.

## Repository Contents
* `README.md`: Project overview and directory guide.
* `solution_report.md`: The complete business and technical design report detailing the 8 tasks of the AI solution design.
* `diagrams/solution_architecture.png`: A visual representation of the proposed AI system architecture and workflow.

## How to Review
1. Start by reading the `solution_report.md` to understand the business problem, proposed AI model, evaluation metrics, and responsible AI considerations.
2. Review the `diagrams/solution_architecture.png` to see how the data flows from the Claims Management System through the AI model and into the hands of the Fraud Investigation Unit (FIU).

## Note on Architecture Diagram
The architecture diagram was generated to show the Human-in-the-Loop (HITL) process, ensuring that the AI acts as a triage system rather than an automated rejection engine.
